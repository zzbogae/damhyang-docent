구역마다 어울리는 소리

화면 구역(P0~P13)을 누르면 그 자리의 바탕 소리로 바뀝니다. 아래 효과음과 민디 목소리는 버튼 하나로 들어 볼 수 있습니다. 브라우저 규칙상 첫 소리는 「소리 켜기」를 눌러야 납니다.

꺼짐

소리는 사용자가 어디에 있는지에만 반응합니다. 기록 내용(힘들었던 주, 광석 종류·등급)으로 소리를 바꾸지 않습니다. 모든 광석은 같은 「쨍」입니다.

구역별 바탕 소리

0.00 · 지상

깊이는 P5~P8에서만 작동합니다. 0 → 1로 갈수록 음량 100%→55%, 고음 18 kHz→2.5 kHz, 울림 0.4초→2.8초. 바람이 사라지고 저주파와 물방울이 나옵니다.

페이지에 붙이는 법

<script src="sound/mined-sound.js"></script>
<script>
  MineDSound.init({ base: 'sound/audio/' }).bind(document);
</script>

<!-- 1. 버튼에 효과음 -->
<button data-sound-toggle>소리 켜기</button>
<button data-sfx="door">ENTER</button>
<button data-sfx="confirm">내려간다</button>

<!-- 2. 화면 구역: 60% 이상 보이면 자동 전환 -->
<section data-sound-zone="P3">관측소…</section>

<!-- 3. 앱 상태에 맞춰 직접 부르기 (React 등) -->
MineDSound.setZone('P6');                 // 연도 지층
MineDSound.setDepth(layerIndex / layerCount); // 몇 번째 층인지로만
await MineDSound.descend(0.6, 3.5);        // 엘리베이터
MineDSound.sfx('pick'); MineDSound.sfx('ore_crack');
MineDSound.say(bubbleText, { tone: 'quiet' });
MineDSound.setZone('P12', { env: 'sea' });
합성음은 모두 mined-sound.js 안에서 만듭니다(외부 음원 없음). 파일 소리 4종(파도·방·문·나무 발소리)은 10/3 섬 영상 C02~C05 원음에서 잘라 냈고, 파일이 없으면 합성음으로 대신합니다. 음악 트랙(C층)은 아직 없습니다.
