## 한 줄 요약

화면 P0~P13 전체에 바탕 소리·효과음·음악·민디 목소리가 붙었습니다. 빠진 곳은 없고, 민디 목소리는 외계어 목소리 B로 확정했습니다.

## 무엇이 들어 있나

| 층 | 내용 | 상태 |
|---|---|---|
| 바탕 소리 | 구역별 바탕, 깊이에 따라 먹먹해짐, 관측소 장면 4종, 나의 공간 환경 5종 | 제안 (청취 확인 필요) |
| 효과음 | 31종, 화면·버튼 118항목과 대조 완료 | 제안 |
| 음악 | 8/22 Suno 홈페이지 곡 3구간: 안개 P0~P2 · 등불 P3·P4·P9·P10 · 열린 곳 P11·P12. 지하 P5~P8은 음악 없음 | **공유 확정** (보별 「음악은 아무 문제 없음」) |
| 민디 목소리 | 외계어 목소리 B: 뜻 없는 낱말 40개 + 대사 상황별 곡조 12개 | **확정** (보별 10/23) |

## 민디 곡조 12개

| 곡조 | 쓰는 곳 |
|---|---|
| 설명 (explain) | 해설 말풍선 기본 |
| 인사 (hello) | 첫 만남, 「오셨네요」 |
| 질문 (ask) | 문장 끝이 ? |
| 응원 (cheer) | 문장 끝이 ! |
| 위로 (comfort) | 조용히 건네는 말 |
| 생각 (think) | 문장 끝이 … |
| 놀람 (surprise) | 「어, 결이 다르네요」 |
| 찾았다 (found) | 광석 있는 층 |
| 캐기 성공 (mined) | P7 성공 |
| 기다림 (wait) | P5 하강 대기 |
| 영차 (effort) | 곡괭이 탭 |
| 안내 (notice) | 첫 대화 고지 |

## 붙이는 법 (멘토용)

```html
<script src="mined-sound.js"></script>
<script>
  button.onclick = () => MineDSound.enable();          // 첫 클릭에서 켜기
  MineDSound.setZone('P3');                            // 화면이 바뀔 때
  MineDSound.sfx('tap');                               // 버튼
  MineDSound.say('그 무렵 이야기, 들어볼까요?');          // 말풍선 (곡조 자동)
  MineDSound.say('오셨네요.', { mood: 'hello' });       // 곡조 직접
</script>
```

## 지킬 것

- 소리는 구역·깊이·고른 환경에만 반응합니다. 기록 내용으로 소리를 바꾸지 않고, 모든 광석은 같은 「쨍」입니다.
- 민디 목소리는 로컬 TTS로 만들어 외부 서비스로 보낸 것이 없습니다. 청룡사 녹음은 v1.3에서 빠졌습니다.
