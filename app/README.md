# app — 발표용 프로토타입 (10/3)

드라이브 `06_발표_프로토타입/` 의 최신판입니다.

## xrblocks_v2/ — XR Blocks 광석 공간
`MineD_XRBlocks_v2`. 실행: 이 폴더에서 `python3 -m http.server 8080` → `http://127.0.0.1:8080/?formFactor=desktop`

## strata_explorer_v5/ — 3개 지층 탐사 (셸·탐사 스크립트만)
`MineD_Web_Demo_v5` 의 `start.html`·`strata-explorer.js/css` 입니다.
이 셸이 띄우는 `index.html`(실제 기록에서 뽑은 80주 판정과 사진이 들어 있음)과 `landing_0822.html`(README에 「외부 공유 금지」)은 공개 저장소라 올리지 않았습니다. 실행하려면 드라이브의 두 파일을 이 폴더에 복사한 뒤 로컬에서만 엽니다.

같은 흐름을 합성 데이터로 돌리는 앱은 `../webapp/` 입니다.
