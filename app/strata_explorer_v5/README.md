## 실행
`06_발표_프로토타입`에서 `python3 -m http.server 8080` → **`http://127.0.0.1:8080/MineD_Web_Demo_v5/start.html`**
(파일을 더블클릭해 열면 일부 연결이 막힐 수 있으니 반드시 위 주소로)

## 흐름
1. **8/22 랜딩 플로우** (`landing_0822.html`, 원본 그대로): 입장 인트로 → 민디 소개·튜토리얼 → 광물 지하 → 상세
2. 오른쪽 아래 **「세 개의 지층으로 내려가기 ↓」** (4번 상세 화면에서 버튼이 깜빡임, 키보드 `5`/`E`도 가능)
3. **민디 · 오늘의 한 마디** 말풍선 — 날짜마다 바뀌는 8개 문장 중 하나, 옹알이 소리와 함께 한 글자씩
4. 「광석을 캐러 가실래요, 아니면 이야기를 나눌까요?」
   - **광석을 캐고 싶어요** → 3개 지층 탐사(웹 v4 기능: 엘리베이터 · 3회 채굴 · 근거 · 확인 등급 · XR v2)
   - **이야기하고 싶어요** → 「민디에게 묻기」 화면

## 오늘의 한 마디 (8개, 날짜 순환)
- 오늘 하늘은 어제와 다른 모양이에요. 늘 그래왔지만요.
- 강아지는 하루를 다 쓰고 잠들어요. 아무것도 남겨두지 않고요.
- 걸음이 적은 날에도 지층은 한 겹 쌓여요.
- 어제 남긴 메모가 오늘은 조금 다르게 읽힐지도 몰라요.
- 바다는 매일 같은 자리에서 다른 파도를 보내요.
- 기록이 없는 날도 비어 있는 날은 아니에요.
- 오늘 처음 마신 물은 몇 시였을까요.
- 오늘의 노을은 오늘만 볼 수 있어요.
→ 가르치지 않고, 판정하지 않는 「무심한 듯 툭」 톤. 창 B에서 문장 풀 확정 시 `start.html`의 `LINES`만 바꾸면 됨
