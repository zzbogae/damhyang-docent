# Mine D 쇼케이스 출품 영상 v0.4 키트

v0.3에서 바뀐 점
- 민디 장면은 원본 민디 이미지를 합성한 `comp/*.mp4`(render_story.py)로 바꿔 캐릭터 일관성을 지킵니다. 굴에서 걸어 나와 서는 컷(기원 영상 C08)을 되살렸습니다.

- 효과음은 앱 사운드(mined-sound.js)를 그대로 렌더링한 `sfx/*.flac`, 바탕 소리는 사운드 키트 amb_room_tone 입니다.

```
cd showcase/v0.4_kit
python3 build4.py --sea <바다> --sky <하늘산> --jungle <정글> --music <음악방> --out <출력.mp4>
```
- `../v0.3_kit/gen/K01.mp4`, `K10.mp4`(Flow 클립), `../v0.3_kit/assets`, `../v0.3_kit/myspace.json` 을 함께 씁니다.
