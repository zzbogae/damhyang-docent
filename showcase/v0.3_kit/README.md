## 실행 (맥)
```
cd showcase/v0.3_kit
python3 build3.py --sea <바다_완성본_v1.mp4> --sky <하늘산…> --jungle <정글…> --music <음악방…> --out <출력.mp4>
```
- `FAST=1` 을 앞에 붙이면 960×540 시험판.
- 나의 섬 구간은 `myspace.json` ({"sea": [시작, 끝], …}) 이 있으면 그 값을, 없으면 각 클립의 마지막 14초를 씁니다.
- 이야기 클립 `gen/K01.mp4 K02 K03 K06 K10` 이 없으면 `gen/src/*.png` 정지 이미지로 대신합니다.
- 시연 녹화는 `../v0.2_kit/assets/demo_rec2_4k.mp4` 를 씁니다.
- 최종 음량은 -16 LUFS, 트루 피크 -1.5 dB로 맞춥니다.
