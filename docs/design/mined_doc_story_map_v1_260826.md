## 0. 이번 수정의 축 — 캐릭터는 민디 하나

**결정: MINDY · ECHO · DIG · LUME · ROOT → 민디 1인.**

### 왜 하나여야 하는가 (발표에서 그대로 쓸 수 있는 논리)

캐릭터가 다섯이면 **판정하는 입이 다섯 개**가 됩니다.

| 캐릭터 | 현재 말버릇 | 무엇이 되는가 |
|---|---|---|
| ECHO | "오오! 이런 패턴이 보이네요!" | **해석자** — 앱이 의미를 붙입니다 |
| ROOT | "조금씩, 천천히, 잘 자라고 있어요" | **평가자** — 우리가 v6에서 지운 위로 문장 |
| LUME | "빛이 이끄는 쪽으로 가보세요" | **권유자** — 민디는 권하지 않습니다 |

> **우리가 문장에서 지운 것이 캐릭터 형태로 되살아나 있었습니다.**
> 다섯을 하나로 줄이는 건 디자인 정리가 아니라 **원칙 복구**입니다.

그리고 실무적으로도 — 5분 발표에서 캐릭터 다섯을 소개할 시간이 없습니다.
11월 부스에서 3D로 만들 캐릭터도 하나면 됩니다.

### 민디 = DIG의 몸 + ECHO의 얼굴

이미 그렇게 그려져 있습니다. 세 번째 이미지(3D 홀)를 보면
**고깔모자 캐릭터 위에 검은 말풍선 얼굴이 떠 있습니다.** 두 캐릭터가 아니라 **한 캐릭터입니다.**

| 요소 | 출처 | 의미 |
|---|---|---|
| 몸 | DIG — 고깔모자 · 눈을 가로지르는 검은 띠 · 니트 로브 · 광물을 안음 | **들여다보지 않는다** |
| 얼굴 | ECHO — 검정 라운드 + 노란 두 눈 + 웃는 입 | **말할 때만 눈을 뜬다** |
| 도구 | DIG의 곡괭이 | 캐는 건 사용자가 시킬 때 |

> **"민디는 눈을 가리고 있습니다. 말할 때만, 말풍선에서 눈을 뜹니다."**
> 캐릭터 그림 한 장으로 절대 원칙 2번이 설명됩니다. 이걸 두 캐릭터로 쪼개놓으면 이 문장이 죽습니다.

### 나머지 셋은 지우는 게 아니라 **사물로 내립니다**

| 없어지는 캐릭터 | 어디로 가나 | 왜 |
|---|---|---|
| **ECHO** | 민디의 **말풍선 얼굴** | 위 |
| **LUME** | 관측소의 **등불** (프롤로그 01 등대 · 지층의 불빛) | 빛은 이미 있습니다. 인격을 붙일 필요가 없습니다 |
| **ROOT** | 화분에서 **저절로 자라는 식물** | 세계관설계서 5장에 이미 「저절로 자라는 것」으로 있습니다. 관리자가 필요 없습니다 |

**핵심 규칙 한 줄** — 문서에 박아주세요:

> **역할은 남기고 인격만 없앱니다. Mine D에서 말을 하는 것은 민디뿐입니다.**

## 1. STORY MAP — 칸별 수정표

### 1-0. 제목 ⚠ 가장 먼저

| | 지금 | 고칠 것 |
|---|---|---|
| 타이틀 | `MIND D – STORY MAP` | **`Mine D – STORY MAP`** |

**`MIND D`가 아니라 `Mine D`입니다.** 확정된 표기입니다.
`Mine D`를 "마인드"로 읽어야 **Mind ↔ Mine D** 말장난이 삽니다. `MIND D`로 적으면 그냥 오타로 보입니다.
부제 "마음의 결을 찾아 떠나는 여정"은 **그대로 둡니다** — 「결」은 코어 단면의 줄무늬 이름으로 살아 있습니다.

### 1-1. 그대로 두는 칸 ✅

**03 · 05 · 07 · 13** — 문장·구조 다 맞습니다. 손대지 마세요.
특히 **07 사실 한 줄**("이 주는 보통보다 새벽 2~4시 활동이 많았던 시기입니다 ✓교차검증")은
판정 없이 사실만 말하는 우리 원칙의 그림입니다.

### 1-2. 고치는 칸

#### 01. 프롤로그 — 안개 속의 발견
| | |
|---|---|
| ❌ | "마인디가 **눈을 뜨며 당신을 맞이합니다**" |
| ✅ | "민디는 이미 그 자리에서 다음 코어를 손질하고 있습니다. **먼저 맞이하지 않습니다.**" |

> 「먼저 말 걸지 않는다」가 첫 칸에서부터 깨져 있었습니다.
> 그리고 "마인디"(서비스)가 아니라 **"민디"**(캐릭터)입니다. 표기 주의.

#### 02. 데이터의 흔적을 모으다 — ⚠ **유튜브가 통째로 빠져 있습니다**
| | |
|---|---|
| ❌ | 건강 · 메모 · 사진 · 캘린더 · 카카오톡 · **AI 대화(미반영)** |
| ✅ | 건강 · 메모 · 사진 · 캘린더 · 카카오톡 · **유튜브** |

| 채널 | 현재 실측으로 교체 |
|---|---|
| 건강 | 7,482건 · 537주 |
| 메모 | 3,097개 (원문 1,124) · 741주 |
| 사진 | **20,465건** (3,699장 아님) · 613주 |
| 캘린더 | 792건 · 148주 |
| 카카오톡 | **2,045건 · 완료** ("처리 중" 아님) |
| **유튜브** | **42,681건 · 369주** ← 신규 |

> **유튜브를 빼면 검증 서사의 절반이 사라집니다.** v4(150배 표류)도, 유단희님 78% 단일출처 사례도
> 전부 유튜브에서 나왔습니다. **AI 대화는 채널이 아니라 기능**이라 이 줄에서 빼야 합니다.

#### 03. 분석의 동굴 — 숫자만
798주 → **796주** / 후보 137건 → **204건** (판정 772주는 맞음)

#### 04. 탐사의 시작 — 라벨 ⚠
| | |
|---|---|
| ❌ | 빛나는 시기 **(먼저 말 걸어도 되는 시기)** 74주 / 조용한 시기 63주 |
| ✅ | **바로 열리는 시기 36주** / **한 번 묻고 여는 시기 44주** |

> "먼저 말 걸어도 되는 시기"는 **우리 원칙과 정반대 표기**입니다. 민디는 어느 시기에도 먼저 말하지 않습니다.
> 차이는 "말을 거는가"가 아니라 **"열 때 한 번 묻는가"**입니다.
> ★ 숫자는 최신 `gyeol_data.json` 기준으로 보경님이 한 번 확인해주세요 (앱 데모 80주 기준).

#### 06. 코어 단면 — 히트맵 → 4축 게이지
"AI가 만든 것이 아닌, 당신의 기록을 기반으로 계산된 무늬" — **이 문장은 완벽합니다. 유지.**
다만 그림을 **일별 걸음수 히트맵** 대신 **4축 게이지**로 바꿉니다.

```
              적음        내 평소       많음
걸음    ·······[▓▓▓▓▓▓▓]···●···
잠      ···●···[▓▓▓▓▓▓▓]·······
화면    ·······[▓▓▓▓▓▓▓]··········●
기록    ··●····[▓▓▓▓▓▓▓]·······
```
회색 띠 = **내 평소 범위**. 좋음/나쁨 없이 적음/많음만. (축 이름 확정: 걸음·잠·화면·기록)

#### 08. 원본 위치 안내 → **그때 쓴 글 · 그때 찍은 사진**
| | |
|---|---|
| ❌ | "그 기록이 어디에 있는지 안내합니다" + 앱 이름·날짜 목록 |
| ✅ | 원문을 **그대로** 보여줍니다. 요약도 교정도 하지 않습니다 |

> 위치 안내는 v3 이전 상태입니다. **지금 앱은 원문을 직접 붙입니다** (49개 주 · 145개 글).
> "해석은 당신의 몫입니다"는 유지.

#### 09~10. 화분 · 정원 — ROOT 삭제 반영
- **10번 칸에서 ROOT 캐릭터를 뺍니다.** 정원에는 사람이 없습니다
- 문장: "모든 결실을 통해 당신만의 정원이 자라납니다" → **"들여다본 자리에서만 자랍니다. 아무도 돌보지 않습니다."**

#### 11. 민디와의 대화 — 말풍선 방향을 뒤집습니다
| | |
|---|---|
| ❌ | 민디: "요즘 마음은 어때?" → "조금 지쳤지만, 그래도 나아지고 있어" |
| ✅ | **사용자**: "요즘 다시 잠을 못 자요."<br>**민디**: "2017년 4월 3일이 가장 가깝습니다. **그 주를 열어보시겠어요?**" |

캡션: *민디가 먼저 묻지 않습니다. 답은 실제 판정값에서 계산되고, 어디를 보면 되는지까지만 말합니다.*

> **현재 그림은 앱이 먼저 묻고, 답이 감정 판정 + 회복 서사입니다.** 우리가 v1·v6에서 지운 문장 형태 그대로입니다.
> 이 한 컷만 바꾸면 「먼저 말 걸지 않는다」가 그림으로 증명됩니다.

#### 12. 아이템과 재료 — 감정어 2개 교체
| 지금 | 고칠 것 |
|---|---|
| **감정의 파편** | **표본 라벨** |
| **회복의 조각** | **바랜 라벨** |

나머지 4종(빛의 결정·기억의 씨앗·시간의 모래·마음의 열쇠)은 유지.
캡션: *이름은 앱이 붙이지 않습니다. **당신이 고릅니다.***

> 광물 이름을 쓴 이유가 감정에 이름을 붙이지 않기 위해서였습니다. 여기서 무너져 있었습니다.

#### 14. 힐링 리포트 → **나에게 보내는 편지**
| | |
|---|---|
| ❌ | "**잘 하고 있어요.** 오늘의 작은 선택들이 모여 당신을 만들고 있어요." |
| ✅ | 앱이 인쇄: `2026년 8월 20일 · 이 주는 새벽에 남긴 글이 평소보다 많았습니다.`<br>**그 아래는 빈칸.** 사용자가 씁니다 |

민디 한 줄: **"무엇을 쓰실지는 제가 모릅니다. 종이만 놓아두겠습니다."**

> 「힐링」이라는 단어를 뺍니다. 상담·치료로 읽히고 우리는 그쪽이 아닙니다.
> 그리고 완전한 바넘 문장이라 심사에서 가장 먼저 찔릴 자리입니다.

#### 15. 엔딩 → **항구 · 다음 항해**
| | |
|---|---|
| ❌ | "**엔딩** – 새로운 항해 / 더 깊은 바다, 더 넓은 세상으로!" |
| ✅ | "**항구** – 다음 항해 / 관측소는 닫히지 않습니다. **층은 매주 하나씩 늘어납니다.**" |

> 엔딩이 있으면 「의도된 미완결」이 깨집니다. 그리고 이 수정이 **「미래 축이 없다」는 구멍을 메웁니다** —
> 매주 층이 하나 늘어난다는 게 미래입니다.

### 2-1. 삭제 (3블록)

### 2-2. 민디 1인 카드 (교체본)

```
민디  MINDY
─────────────────────────────
역할     길잡이
성격     묻지 않는다. 판정하지 않는다. 위치만 안다
말버릇   "어디를 보면 되는지는 압니다."
특징     눈을 가리고 있습니다. 말할 때만, 말풍선에서 눈을 뜹니다
```

**바로 옆에 이 표를 붙여주세요 — 이게 관계도 자리를 대신합니다.**

| 민디가 하는 것 | 민디가 하지 않는 것 |
|---|---|
| 언제였는지 말한다 | 왜 그랬는지 말한다 |
| 어느 앱, 어느 날짜인지 가리킨다 | 무슨 뜻인지 해석한다 |
| 물으면 답한다 | 먼저 말을 건다 |
| 원문을 그대로 꺼낸다 | 요약하거나 다듬는다 |
| 매주 코어를 캐서 올려둔다 | 열어보라고 권한다 |

> 관계도보다 이 표가 낫습니다. **심사위원이 궁금해하는 건 캐릭터끼리의 사이가 아니라
> "이 AI가 어디까지 하느냐"입니다.** 그 답이 한 장에 있게 됩니다.

### 2-3. 「사물이 된 것들」 블록 신설 (캐릭터 자리에)

| | 사물 | 원래 | 설명 |
|---|---|---|---|
| 🏮 | **등불** | LUME | 지층마다 켜져 있습니다. 어디로 가라고 하지 않습니다 |
| 🌱 | **식물** | ROOT | 들여다본 코어 곁에서 저절로 자랍니다. 돌보지 않아도, 돌봐도 |
| 💬 | **말풍선** | ECHO | 민디의 얼굴입니다. 별개 존재가 아닙니다 |

> **3D 작업(이승현)에 직결됩니다.** 세 번째 이미지에서 떠 있는 검은 얼굴은
> **독립 캐릭터가 아니라 민디의 말풍선**입니다. 애니메이션도 그 전제로 붙여야 합니다 —
> 따라다니는 동료가 아니라, **민디가 말할 때만 켜지는 얼굴**.

### 2-4. 세계관 헤더
