# 내 데이터로 「결」 돌려보기
팀원용 안내 | 30분 | 어려운 건 없습니다. 순서대로만 하시면 됩니다

---

## 먼저 알아둘 것

**당신의 기록은 당신 컴퓨터 밖으로 나가지 않습니다.**
전부 본인 맥/PC에서 돌아가고, 결과 파일도 본인 것만 생깁니다.
저희에게 보내실 필요도 없습니다. **만든 파일은 본인만 가지고 계시면 됩니다.**

---

## 1. 내보내기 (제일 오래 걸립니다 — 먼저 신청해두세요)

### ① 구글 Takeout — **지금 바로 신청하세요. 메일이 오는 데 몇 시간~하루 걸립니다**

1. `takeout.google.com` 접속
2. **모두 선택 해제** 누르고, 아래 3개만 체크
   - **YouTube 및 YouTube Music** → "여러 형식" → 기록을 **JSON**으로
   - **Google 포토**
   - **캘린더**
3. 내보내기 → 메일 오면 zip 다운로드

### ② 애플 건강 (아이폰)

건강 앱 → 오른쪽 위 **내 프로필** → 맨 아래 **모든 건강 데이터 내보내기**
→ `내보내기.zip` 생성 → 맥으로 옮기기 (에어드롭이 제일 빠릅니다)

> 용량이 큽니다(수백 MB). 놀라지 마세요. 실제로 쓰는 건 **걸음수·수면·운동뿐**입니다.

### ③ 카카오톡 (선택)

대화방 → 메뉴 → **대화 내용 내보내기** → 텍스트만 → 메일/파일로 저장
→ 필요한 대화방 몇 개만 하셔도 됩니다

### ④ 메모 (선택)

맥 메모 앱 → 전체 선택 → **파일 > 다음으로 내보내기 > PDF** … 는 안 됩니다.
메모는 지금 자동 추출이 어렵습니다. **건너뛰셔도 됩니다.**

---

## 2. 폴더 만들고 파일 넣기

바탕화면에 `gyeol_kit` 폴더를 만들고, 그 안에 `data` 폴더를 만듭니다.
받은 파일을 **압축 푼 채로** `data` 안에 넣습니다.

```
바탕화면/gyeol_kit/
├── data/          ← 여기에 내보낸 파일 전부
└── (코드 파일들)   ← 보경이 보내드립니다
```

**코드 파일(`.py`)은 보경님께 요청하세요.** 팀방에 올려드립니다.

---

## 3. 돌리기

터미널을 엽니다 (스팟라이트에서 `터미널` 검색).

```
cd ~/Desktop/gyeol_kit
python3 run_gyeol.py
```

끝나면 폴더 안에 **`gyeol_data.json`**이 생깁니다. **이게 당신의 관측소입니다.**

---

## 4. 열어보기

1. 팀방에 올라온 **`gyeol_app.html`**을 받습니다 (미리보기 버전 말고 이쪽)
2. 더블클릭 → 브라우저에서 열림
3. 화면에 **`gyeol_data.json`을 끌어다 놓기**
4. 코어를 **곡괭이로 세 번** 치면 캐집니다

**사진도 보고 싶으면**: 상단 **"사진 폴더"**를 누르고 사진 폴더를 고르면 됩니다.
사진 역시 브라우저 밖으로 안 나갑니다.

---

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 후보가 하나도 안 나옴 | 데이터가 **6개월 미만**입니다. 최소 6개월, 12개월 권장 |
| "교차검증 안 됨"만 잔뜩 | 채널이 1~2종뿐입니다. 정상입니다. **그것도 결과입니다** |
| 사진이 하나도 안 붙음 | 앱 화면에 **왜 안 붙었는지 표로 나옵니다.** 그걸 보내주세요 |
| `python3` 없다고 나옴 | 터미널에 `xcode-select --install` 입력 후 다시 |
| 그 외 | **에러 메시지를 통째로 캡처해서** 팀방에 올려주세요 |

## 돌려보시고 알려주셨으면 하는 것 3가지

1. **지목된 주를 보고 뭐가 떠올랐나요?** (아무것도 안 떠올라도 그대로 알려주세요)
2. **문장이 불쾌하지 않았나요?** 차갑거나, 참견 같거나
3. **"교차검증 안 됨" 표시를 보고 어땠나요?**

> 데이터가 얕게 나와도 괜찮습니다. **그것도 발표에 쓰는 결과입니다.**
> 실제로 팀원 네 명 중 완전한 데이터를 가진 건 한 명뿐이었고,
> 그 사실 자체가 기획서의 한계 항목으로 들어가 있습니다.
