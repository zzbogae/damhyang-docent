# Mine D — 공간 생성 설계 (v2)

**2026.09.26 · 데이터·코드 창 · v1 폐기, 이 문서가 정본**

> **v1이 틀렸습니다.** v1은 「앱이 집계를 보고 제약을 도출한다」로 짰습니다.
> 보경 님 지적대로 **사용자가 민디와 대화하며 정하는 것**이 맞습니다.
> 그 차이가 설계 전체를 바꿉니다 — §1 참고.

---

## 1. 무엇이 바뀌었나 — 앱이 도출하지 않습니다

### v1 (폐기)
```
집계 → LLM이 제약조건을 도출 → 공간
```
앱이 사용자 데이터를 보고 「이런 공간이 어울린다」를 정합니다.
**그건 해석입니다.** 아무리 주어를 공간으로 바꿔 써도, 정한 건 앱입니다.

### v2 (확정)
```
집계 → 민디가 사용자에게 보여줌 → 사용자가 대화로 정함 → 공간
```
민디는 **재료를 꺼내놓을 뿐**이고, 「어떤 공간이 될지」는 사용자가 말합니다.

**이게 절대원칙 1을 구조적으로 해결합니다.** 규칙으로 막는 게 아니라, 해석하는 주체가 애초에 앱이 아니게 됩니다. v1의 「주어는 공간」 규칙은 이제 필요 없습니다 — 사용자가 자기 공간을 말하는 데 주어 제약을 걸 이유가 없습니다.

### 덤 — L1 병목이 우회됩니다

L1은 「하위 3%」·「뒤 4주가 평소 범위」를 사람 말로 바꾸는 문제였습니다.
**공간 생성의 재료는 처음부터 사람 말입니다** — 자주 쓴 단어, 최근 새로 나타난 말.
통계 문장을 번역할 필요가 없습니다. L1은 광물 화면 쪽에 그대로 남지만, 여기서는 안 걸립니다.

---

## 2. 재료 — 무엇을 꺼내 보여주나

`freq_scan.py` 가 만듭니다. **지표가 아니라 말입니다.**

| 재료 | 예 |
|---|---|
| **자주 쓴 말** | `작업실` 412번 · `산책` 188번 |
| **최근 8주에 새로 나타난 말** | `전시` · `코엑스` — 이전 52주엔 없던 말 |
| **최근 8주에 부쩍 늘어난 말** | `정리` 3.2배 |
| 의미 있는 광석 | 그 주의 `gem` · `grain` · 등급 |

「밤 발화 29%」 같은 비율은 **참고로만 둡니다.** 대화를 여는 말이 아닙니다.
**「최근 새로 나타난 말」이 가장 강한 재료입니다** — 지금의 나에 대한 것이고, 사용자가 바로 알아봅니다.

## 3. 세 개의 층 [확정 — W2 답]

지금까지 만든 디자인을 버리지 않습니다. 위에 한 층을 얹습니다.

```
    ┌─ ③ 원하는 공간 ─────────── 대화로 짓습니다. 새 층
    │     민디와의 대화 + 고른 광석으로 사용자가 설계
    │
    ├─ ② 광석 ───────────────── 지층에 박힌 사물
    │     깨면 기억 하나가 열림. 종류·색·크기는 axes.py 가 정함
    │
    └─ ① 지층 ───────────────── 공간. 자동 생성
          과거로 갈수록 깊이 내려감. 시간이 축
```

**W2 답 — 광석은 사물입니다. 공간이 아닙니다.**
공간은 **지층**이고, 광석은 그 지층에 박혀 있습니다. 796주면 광물 129개인데 그게 방 129개가 되면 걸어다닐 수 없는 월드가 됩니다.

**세 층은 규칙이 서로 다릅니다. 스키마에서 갈라야 합니다.**

| 층 | 무엇이 만드나 | 언제 자라나 |
|---|---|---|
| ① 지층 | 데이터 (자동) | 주가 쌓이면 |
| ② 광석 | `axes.py` 판정 (자동) | 주가 쌓이면 |
| ③ 원하는 공간 | **사용자의 대화** | **대화가 쌓이면** |

①②는 사용자가 아무것도 안 해도 자랍니다. ③은 말해야 생깁니다. 섞으면 「내가 안 한 것을 내가 한 것처럼」 보입니다.

## 4. 언제 갱신되나 [W1 답 — 대화가 조건]

보경 님 안대로 **챗봇 대화 축적이 조건**입니다. 구체안:

| 조건 | 제안값 | 왜 |
|---|---|---|
| 대화 턴 | **20턴** 이상 | 한두 마디로 공간이 바뀌면 가벼워집니다 |
| 서로 다른 광석 | **3개** 이상 언급 | 한 기억만으로 지은 공간은 그 기억의 삽화입니다 |
| 최소 간격 | **7일** | 매일 바뀌면 「내 공간」이 안 됩니다 |

셋을 **모두** 만족했을 때 한 번 자랍니다. 그리고 **조용히** 자랍니다 — 알림 없습니다(절대원칙 3). 다음에 들어가면 달라져 있습니다.

⚠ 숫자는 제안입니다. 실제 대화가 쌓여봐야 압니다. **지금 확정하지 말고 스키마에 파라미터로 빼둡니다.**

---

## 5. 제약이 부딪히면 [W3 — 질문 자체를 고쳤습니다]

**W3이 뭘 묻던 거였나** — 「어둡게 해줘」와 「탁 트이게 해줘」가 같이 오면, 둘 다 만족하는 공간이 없습니다. XR Blocks는 둘 중 뭘 먼저 적용할지 몰라서 멈추거나 이상한 걸 만듭니다. v1에서는 앱이 혼자 정해야 해서 규칙이 필요했습니다.

**v2에서는 질문이 사라집니다. 사용자가 이미 대화 중이니까요.**

> 부딪히면 **민디가 되묻습니다.** 「어두운 쪽과 트인 쪽 중 어디에 가깝게 둘까요」
> 이건 절대원칙 3과 부딪치지 않습니다 — 사용자가 먼저 연 대화 안이니까요.

**되묻지 않고 앱이 조용히 하나를 고르면 안 됩니다.** 그 순간 앱이 해석한 게 됩니다.

## 6. 스키마 [초안]

```jsonc
{
  "schema": "mined.world.v0",

  "strata": {                       // ① 지층 — 자동
    "depth_unit": "week",
    "oldest": "2011-W03", "newest": "2026-W39"
  },

  "gems": [                         // ② 광석 — axes.py 그대로. 재계산 없음
    { "week": "2023-W12", "gem": "pyrite", "grain": "coarse",
      "depth": 178, "grade": "broken",
      "return_week": "2023-W15", "hold_until": "2023-W19" }
  ],

  "designed_spaces": [              // ③ 원하는 공간 — 대화로만
    { "id": "s1",
      "from_gems": ["2023-W12", "2021-W44", "2019-W07"],
      "said": "창이 하나만 있는 낮은 방",      // 사용자의 말 그대로
      "xr": { "windows": 1, "ceiling": "low", "lights": 1 },
      "turns": 23, "created": "2026-10-02" }
  ],

  "growth_rule": { "min_turns": 20, "min_gems": 3, "min_days": 7 },
  "world_state": { "version": 7, "last_grown": "2026-10-02" }
}
```

### 하드룰 [확정]

1. **원문은 안 들어갑니다.** `said` 는 **공간에 대해 사용자가 한 말**이지 메모·카톡 원문이 아닙니다
2. **광석은 `gyeol_axes.json` 을 그대로 씁니다.** 재계산 금지 — 두 벌이면 버그
3. **`designed_spaces` 는 지우지 않고 쌓습니다.** 지난 공간을 지우면 「이미 한 번 여기를 지나갔다」가 성립하지 않습니다
4. **`broken` 인 주는 월드에서도 비워둡니다.** 문안이 없는데 월드가 대신 말하면 안 됩니다
5. **지층은 사용자가 못 고칩니다.** 시간은 기록이지 취향이 아닙니다

## 7. 내일 순서

| | 할 일 |
|---|---|
| 1 | `data/` 찾기 — 다운로드는 했는데 `gyeol_kit/data` 에는 없습니다 |
| 2 | `freq_scan.py --list-speakers` → `--me "이름"` |
| 3 | `out/freq_for_llm.json` 붙여넣기 |
| 4 | **민디와의 대화를 실제로 해봅니다** — 그 재료로 공간이 정해지는지 |
| 5 | 그 대화에서 나온 공간 2~3개를 가상 시나리오로 (v5 §5-3) |

**4번이 이번 발표의 핵심 장면입니다.** 「AI가 분석했습니다」가 아니라 **「사용자가 자기 데이터를 보며 자기 공간을 말했고, 그대로 지어졌습니다」** 가 보여줄 것입니다.

## 8. 창 B로 넘길 것

1. **`broken` 화면 문안** — 광물 주의 47%. 아직 비어 있습니다
