# 「결」 세계관 · 메커닉 설계 문서

## 핵심 한 문장

> 힘든 시기엔, 예전에도 이랬다가 지나갔다는 걸 스스로 기억해내지 못한다. 「결」은 그 기억을, 내가 직접 남긴 증거로 대신 꺼내준다.

## 세계관

- **관측소** = 안개 속 광산 (유단희 이미지 기반). 무의식·미처 인지 못한 축적 데이터를 캐내는 곳.
- **결지기** = 사용자가 없는 동안에도 혼자 관측소를 지키며 채굴해온 존재. 키우는 펫이 아니라 원래 있던 관리자.
- **코어** = 한 주의 데이터가 압축된 광물. 채널별 색: 옵시디언·자수정·라피스·호박.
- **강** = 시간의 흐름(과거→현재). 강가를 따라 코어가 놓여 있어, 위치만으로 "언제"인지 읽힌다.
- **바다** = 강이 모이는 곳. 연결된 채널 수·데이터 총량에 따라 폭이 넓어짐.
- **바람** = 새로 밝혀질 준비가 된 지점의 신호. 알림 배지의 자연스러운 대체. (감정 판정에는 쓰지 않음 — 구조 신호 전용)
- **사운드** = 채널별 배경음 레이어. 연결할수록 관측소의 소리가 한 겹씩 두꺼워짐.

## 핵심 메커닉

1. 설치 즉시 몇 년치 지도가 안개 낀 채로 이미 존재한다 (텅 빈 시작이 아님).
2. **탐사**: 알림을 기다릴 필요 없이, 아무 때나 원하는 지점을 파볼 수 있다.
3. **채굴 연출**: 코어는 바로 갈라지지 않고 안개가 서서히 걷히며 드러난다.
4. **선택**: 화분에 심기(꽃이 실제 시간 좌표에 자람) 또는 재료 획득(지역별 자연 재료, 나중에 건축용).
5. 재료가 쌓이면 미니어처 건축이 조용히 가능해진다 (진행률 표시 없음, 발견하듯 열림).
6. 채널을 새로 연결하면: 이미 심어둔 봉오리 중 교차검증되는 것들이 만개로 바뀌고, 사운드 레이어가 하나 추가된다.
7. **결지기에게 묻기**: 사용자가 능동적으로 질문해서 스스로 조각을 찾는다. 모르면 모른다고 답하고, 답은 항상 실제 기록에 근거한다.

## 인출 필터 원칙 (개정)

- **자동 알림(먼저 말 걸기)**: 가장 두드러진 시기는 계속 제외한다. 원치 않는 순간 갑자기 마주치는 걸 막기 위함.
- **사용자 직접 탐사**: 전부 접근 가능하다. 다만 가장 두드러진 시기는 한 번의 확인 단계("이 시기를 열어보시겠어요?")를 거친다.
- 이 필터의 이름도 "인출 필터"보다 "먼저 말 걸기 필터"에 가깝게 다시 정의됨.

## 성취감 설계

| 성취 종류 | 채워지는 방식 |
|---|---|
| 지도를 밝힌다 | 직접 탐사한 만큼 안개가 걷힘 |
| 세계가 자란다 | 심은 꽃이 진짜 시간 자리에 남음 |
| 확신이 자란다 | 채널을 늘릴수록 봉오리 → 만개 |
| 무언가 지을 수 있게 된다 | 자연 재료가 쌓이면 미니어처 건축 |
| 이야기를 맞춘다 | 결지기에게 물어 스스로 탐색 |
| **나만의 공간이 열린다** | **화분이 쌓이면 1인칭 개인 공간 언락 (아래 상세)** |

## 1인칭 개인 공간 (신규, 11월 목표)

- 화분(들여다본 코어)이 쌓이면 조용히 새 공간이 열림 — 진행률 표시 없음
- 공간 테마는 사용자가 고르지 않음 — **기존 모양 분류기(위축형/확장형)** 누적 결과로 결정
  - 확장형 누적 다수 → 바다·들판 등 열린 공간
  - 위축형 누적 다수 → 폐가·방 등 닫힌 공간
- 1인칭 시점, 걸어 들어가는 느낌
- "꾸민다"의 실체: 새로 만들거나 사는 게 아니라, **이미 화분에 있던 진짜 꽃·표본을 공간 안에 배치**만 함 (원칙 4 유지)
- 화분이 더 쌓이면 공간이 추가로 열림 — 사람마다 다른 개수·조합의 공간을 갖게 됨
- 난이도: 8/22엔 컨셉 슬라이드 + (가능하면) 정지 이미지 1장까지만. 실제 구현은 11월 목표

## 결지기에게 묻기 — 응답 소재 (사용자가 먼저 물었을 때만)

- **행동활성화 소재**: "힘들다"는 요청이 오면, 그 사람의 실제 과거 기록에서 비슷한 흐름이었을 때 실제로 했던 행동(산책·물 마심 등)을 근거로 답한다
- 원칙: 시스템이 먼저 감지해서 말 걸지 않는다. 위장된 개입("물 마실래?" 식으로 위험 감지를 포장)도 금지 — 나중에 사용자가 알아채면 다정함이 아니라 감시로 느껴짐
- 답변은 항상 "그 사람 자신의 과거 근거"에서만 나온다 — 일반적인 건강 조언을 지어내지 않는다

## 하지 말아야 할 것

- 며칠 단위 수면·걸음수 감소를 알람으로 띄우는 것 — v1 실패("장례식 주 1주 회복 오판")와 같은 구조
- 위험 신호를 감지해서 우회적으로 말을 거는 것 — "감지해서 알린다"를 다른 포장으로 되살리는 것일 뿐

- 화폐·상점, 임의 구매 아이템
- 스트릭·타이머·실패 상태
- 진행률 바 ("10개 모으면 해금") — 대신 "쌓이다 보니 어느새 가능해짐"
- 재료 종류를 사용자가 직접 고르는 취향 설문 — 대신 실제 캔 지역·데이터로 자연히 정해짐
- 날씨(바람 등)를 감정 판정에 사용하는 것 — 구조적 신호 전용

## 참고 — 왜 이 설계인가

| | Finch / Voidpet | 결 |
|---|---|---|
| 시간 방향 | 미래로 쌓는다 | 과거에서 꺼낸다 |
| 0일차 경험 | 텅 빈 시작 | 몇 년치가 이미 존재 |
| 사용 빈도 | 매일 | 가끔, 묵직하게 (실측 ~16주 1회) |
| 사용자가 하는 일 | 꾸미고 모은다 | 찾아가고 고른다 |
