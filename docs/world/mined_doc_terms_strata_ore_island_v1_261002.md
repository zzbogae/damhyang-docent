## 이유

「3층」이라는 표현이 물리적인 깊이(층이 3개)로 읽혀, 웹사이트의 **연도별로 깊어지는 지층**과 혼동됨. 실제 의미는 「층이 세 개」가 아니라 「서로 다른 종류의 요소 세 가지」.

## 구조 설명

```
        섬    ← 지상. 캔 광석을 들고 올라와 사용자가 이름 붙여 만드는 나만의 공간
   ─────────── (지표면 = 관측소)
   2026 ▒▒▒▒▒▒
   2025 ▒▒◆▒▒▒   ← 지층: 시간 그 자체. 연도별로 아래로 깊어짐 (겹 수 = 데이터 기간)
   2024 ▒▒▒▒◆▒       ◆ 광석: 지층 속에 박힌, 판정 결과가 붙은 특정 주
    ⋮
```

- **지층** = 시간. 연도·주 단위로 수십~수백 겹. 무판단(관측소 원칙)
- **광석** = 지층 안의 특정 주. 데이터가 정함
- **섬** = 지상의 나만의 공간. 사용자가 단어를 고르고 이름 붙임. AI 해석 허용 구역
