## 1. 섬은 이렇게 만들어진다 — 다이빙 시나리오

**장면:** 해변을 바라보다 그대로 깊은 바다로 다이빙해, 천천히 유영하며 고래상어·환도상어·복어 같은 해양 생물을 만나는 1인칭 체험.

**흐름:** 민디가 단어 제시 → 사용자가 「바다」 선택 → 「바다 하면 떠오르는 이미지가 뭐예요?」 → 「바닷속을 천천히 유영하며 고래상어랑 복어랑…」 → 기록 교차(사진: 오래 머문 여행지가 다이빙 바다 / 카톡: 「다이빙 가자」 대화 / 유튜브: 해양생물 채널 / 캘린더: 수영장 일정) → 「연말에 다이빙 가고 싶지만 지금은 바쁘다」 → 1인칭 이미지·영상 생성

**구현 원칙(v10 §2):** 민디는 사실을 펼치고, 결론(「가고 싶다」)은 사용자가 말함.

**다른 재료 예시:** 바다·노을·스쿠버 다이빙, 자전거 여행, 칵테일 한 잔, 내가 찍은 음식 사진에서 추출한 재료와 좋아하는 음식.

## 2. 이 앱이 사용자에게 주는 것

- 일상을 더 기록하고, 스스로를 돌아보고, 마음과 몸을 챙기게 됨
- 그렇게 나를 튼튼하게 만들면서 내가 원하는 꿈의 세계도 구축 — 일거양득
- 내 데이터를 아는 민디에게 친구에게도 못 한 이야기를 털어놓고 공감받음
- 그 이야기가 쌓여 최근의 나와 내 상태를 스스로 알게 됨

## 3. 첫 화면 — 셀프리치다이어리 레퍼런스

레퍼런스 앱의 무작위 「행운지수」 자리에 Mine D는 **최근 나의 상태를 보여주는 대표 광물**(또는 숫자 — v10 D3에서 결정)을 보여줌. 09-03 녹음의 불명확 앱명 = 셀프리치다이어리로 확인.

## 4. 민디의 첫 멘트 — 「무심한 듯 툭」

가르치지 않는, 곱씹게 되는 객관적 한 줄 → 「광석을 캐고 싶으신가요? 아니면 대화를 원하시나요?」 선택. 레퍼런스 문장은 톤만 참고하고 민디 문장은 새로 씀.

## 5. 확장 로드맵 — 발표의 「앞으로」 파트 (D2 정리)

**결정(10/2):** 광석으로 섬 꾸미기·확장·구매는 **이번 MVP에 넣지 않고, 발표에서 확장안으로 소개**. 현재 원칙(스트릭·화폐·상점 없음)은 MVP 기준으로 유지.

| 단계 | 내용 | 비고 |
|---|---|---|
| 지금 (MVP) | 지층·광석·섬 구조, 대화로 섬 1개 열기 | 11월 전시 |
| 확장 1 — 섬 자라기 | 광석이 쌓이면 섬이 확장되거나 새 섬 추가, 소품 선택·꾸미기 | 「기록의 결과로 자람」이지 의무 루프가 아니도록 설계 |
| 확장 2 — 섬 잇기 | 사용자가 늘면 섬끼리 연결: 친구 맺기, 다른 섬 방문하기 | 기본은 비공개. 공유되는 건 **섬(공간)뿐, 원문 기록은 절대 안 보임** |
| 확장 3 — 특화 버전 | 치매 노인을 위한 「기록 열어보고 대화하기」 모델 | 아래 §6 |
| 상용화 | 소품 구매 등 수익 모델 | 원칙 5와의 관계는 이 단계에서 재논의 |

### 추가 아이디어 (보경님 검토용)

1. **함께 만드는 섬** — 같이 간 여행처럼 두 사람의 기록이 겹치는 시기를 「공동 섬」으로. 친구 맺기 다음 단계로 자연스러움
2. **군도(群島) 지도** — 내 섬들이 시간순으로 모여 하나의 군도가 됨. 지층(시간 아래로)과 대칭되는 「시간 옆으로」 시각화
3. **가족 지층** — 부모가 아이의 사진·기록으로 아이 몫의 지층을 대신 쌓아두고, 아이가 커서 열어봄. 치매 버전과 구조가 같음(남이 대신 쌓아주는 지층)
4. **반려동물 섬** — 함께한 시간의 사진·산책 기록으로 만드는 섬. 보경님이 예로 든 강아지 문장과 정서가 이어짐
5. **실물 광석** — 광석을 3D 프린트하고 NFC를 넣어, 손에 쥐면 그 주의 기록이 재생. 치매 버전·전시 굿즈 양쪽에 쓸 수 있음 (09월 녹음의 「물리 블록과 기억」 아이디어와 연결)
6. **기관 연계(B2B)** — 요양시설·지자체 돌봄 사업과 연결하면 치매 버전의 실제 수요처가 생김

## 6. 치매 특화 버전 — 강조 포인트와 주의점

**강조할 점:** 기록을 「캐서」 다시 꺼내 보는 Mine D의 구조가 회상(reminiscence) 활동과 그대로 맞음. 같은 이야기를 몇 번 반복해도 민디는 처음처럼 들어줌.

**설계 아이디어:** 보호자·가족이 사진과 기록을 넣어 지층을 대신 쌓는 보호자 모드 / 글자보다 사진·목소리 중심 / 실물 광석(§5-5)으로 손에 쥐는 회상.

**발표 시 주의:** 「치료」「효과」라고 말하면 의료기기 규제와 근거 문제가 생기므로 **「회상 지원」「기록 열어보기」**로 표현. 본인 동의가 어려운 사용자이므로 보호자 동의 구조가 필요하다는 점도 함께 언급하면 설득력이 높아짐.

## 7. D5 정리 — 내일 데모의 대화 예시

남편·아이 이야기를 털어놓는 장면은 **내일 데모용 예시**임(실제 원문을 외부로 보내는 구조가 아님). 데모 대화는 **가상으로 작성한 시나리오**를 쓰고, 생성 도구에는 시나리오 속 장면 묘사만 넣음. 실서비스에서 원문은 본인 기기 안에서만 처리한다는 원칙은 그대로.
