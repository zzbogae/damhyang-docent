# Mine D 캡스톤-06 발표자 노트

## 1. 표지
Mine D는 내 기록을 판단하는 서비스가 아니라, 기록을 광석과 지층으로 보여주고 사용자가 직접 말한 바람을 섬으로 만드는 프로젝트입니다.

## 2. 지금까지 한 것
15.3년, 796주의 실제 기록을 6개 채널에서 주 단위로 맞췄습니다. 4축과 방향별 기준으로 광물 9종을 결정하고, 확인 등급을 보완해 화면에 설명할 수 있는 주를 18%에서 65%로 늘렸습니다.

## 3. 방향 전환
이전에는 챗봇이 데이터를 설명하는 데 머물렀습니다. 교수님 피드백 뒤에는 데이터와 대화가 광석과 개인 월드를 실제로 생성하고 바꾸는 시스템을 증명하는 방향으로 전환했습니다.

## 4. 지층·광석·섬
지층은 시간, 광석은 평소에서 크게 벗어난 주, 섬은 사용자가 말한 미래 공간입니다. 관측소에서는 판정하지 않고, 섬에서만 사용자의 말을 연결합니다.

## 5. 섬이 열리는 흐름
민디가 기록에서 확인되는 사실을 펼치면 사용자가 원하는 장면을 직접 말합니다. 민디가 욕구를 대신 추론하지 않습니다. 사용자의 말이 섬 설계도가 됩니다.

## 6. AI 자동 생성
원문은 기기 안에 남습니다. 외부 생성 모델에는 사용자가 고른 단어와 장면, 스타일 파라미터만 전달합니다. 키 이미지, 컷 영상, 장면 연결, 사람의 QC를 거쳐 1인칭 섬이 됩니다.

## 7. 데모
주인공은 같은 성인 여성입니다. 보는 풍경이 아니라 맥주를 마시고, 발로 걷고, 손잡이를 잡고, 몸을 던져 잠수하고, 복어에게 조개를 건네는 체험입니다. 접촉·체중·관성·부력이 영상의 설득력입니다.

## 8. 수업과의 인과
수업에서 배운 핵심은 서로 다른 데이터를 모델이 다룰 수 있는 표현으로 바꾸고, 구조화된 입력이 생성 결과로 이어지게 설계하며, 사람이 결과를 다시 검증하는 과정이었습니다. Mine D는 이를 기록→특징→광석→설계도→월드 업데이트로 구현합니다.

## 9. 확장
MVP 뒤에는 광석으로 섬을 확장하고, 원문을 공개하지 않은 채 친구의 섬과 연결하며, 회상 지원 버전과 상용화를 검토합니다. 현재 구현된 기능과 미래 계획을 구분합니다.

## 10. 프라이버시
원문은 기기 밖으로 보내지 않습니다. 생성 모델에는 선택된 단어와 사용자가 말한 장면만 보냅니다. AI는 기록을 진단하거나 과거 의미를 소급 판정하지 않습니다.

## 11. XR Blocks
XR Blocks는 three.js·WebXR 기반이며 데스크톱 시뮬레이터가 있어 섬 탐색과 광석 상호작용 프로토타입에 적합합니다. 다만 공식 지원 제품이 아니므로 전시는 사전 생성 영상 폴백을 함께 둡니다.

## 12. 마무리
내 기록은 판정 없이 광석으로 쌓이고, 민디와의 대화에서 꺼낸 바람이 AI를 거쳐 1인칭으로 들어가는 나만의 섬이 됩니다.
