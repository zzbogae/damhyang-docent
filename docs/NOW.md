### 4축 — 이름이 두 층입니다

'move':  {'label': '움직임', 'screen': '걸음'}

'watch': {'label': '보기',   'screen': '화면'}

'leave': {'label': '남기기', 'screen': '기록'}

### τ — 방향별로 다릅니다

| 축 | τ 위 | τ 아래 |
| :---- | :---- | :---- |
| move | 4.91 | 1.60 |
| rest | 2.21 | 2.99 |
| watch | 2.48 | 1.44 |
| leave | 2.85 | 1.37 |

### 광물 — 축이 정합니다

move up 호박 amber      / down 황철석 pyrite

rest up 청금석 lapis    / down 월장석 moonstone

watch up 자수정 amethyst / down 홍옥 rose

leave up 흑요석 obsidian / down 석류석 garnet

교차검증 형석 fluorite (GEM\_COMPLEX)

난수 아님. 같은 4축 숫자 \+ 같은 직전 52주 이력이면 같은 광물. 카톡·메모의 **내용**은 광물 결정에 들어가지 않음.
