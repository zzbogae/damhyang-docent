## 2. 공간 설계 (위에서 본 배치 · 동선 · 카메라)

규칙: 키프레임마다 몸이 서 있는 자리(●)와 보는 방향(→)을 먼저 정하고, 컷은 그 자리 사이를 실제로 걸을 수 있는 거리로만 잇습니다. 수치는 연출 추정치(±20%).

### 2-1. 바다 — 바위 해안의 오두막과 선착장

```
            북(바다·수평선)
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
   ~  작은 배 ⛵   ║부두║  바위  ~~~~~~~
   ~  K05● (부두 끝, 앉음 → 북서 배)  ~~
   ~~~~~~~~~~ ║부두║ ~~~~~ 모래 ~~~~~~
   K02● 부두 입구 → 북동(부두 따라 오두막)
   바위 언덕                      돌계단
   K01● 전망 난간 → 북동(만 전체)    ↑
                         오두막 [K03● 창 → 북서]
                         테라스 [K04● 의자 → 북서]
   해: 남쪽 높이(점심) — 그림자 짧게 북쪽으로
```

| 자리 | 높이 | 보는 방향 | 이웃 자리까지 |
|---|---|---|---|
| K01 전망 난간(서서) | 1.6 m | 만 전체, 오두막 오른쪽 | → K02 약 30 m, 언덕을 내려옴(컷 사이 생략) |
| K02 부두 입구(서서) | 1.6 m | 부두 따라 오두막 | 컷 안에서 2걸음(1.4 m) |
| K03 오두막 창(서서, 실내) | 1.6 m | 창 너머 부두·배 | K02에서 부두·계단 약 25 m(생략) |
| K04 테라스 의자(앉아) | 1.1 m | 만과 부두 | 창에서 문 지나 4 m(생략) |
| K05 부두 끝(앉아) | 1.0 m | 배와 바다 | 계단·부두 약 25 m(생략) |

이음점(OUT → IN, 같은 방향·같은 소리로 잇기)
- S0 OUT: 안개 걷힌 만 전경 → S1 IN: 같은 화면, 손이 난간에 닿음
- S1 OUT: 손이 난간에서 떨어지고 시선이 부두 쪽(오른쪽 아래)으로 → S2 IN: 부두 입구, 손이 밧줄 기둥
- S2 OUT: 두 걸음 끝, 시선이 오두막 쪽 → S3 IN: 오두막 안, 손이 걸쇠(파도 소리 이어짐)
- S3 OUT: 창이 열리고 바닷바람 → S4 IN: 테라스 의자, 같은 바다를 보며 잔
- S4 OUT: 잔을 내려놓고 시선이 부두 끝 → S5 IN: 부두 끝에 앉은 자리
- S5 OUT: 손이 돌 위에 멈춤, 물소리만 → 끝

### 2-2. 하늘산 — 구름 위 절벽의 한 칸 서재

```
   구름바다(동·남, 아래 300 m 추정)
   ☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁☁
   절벽 가장자리 돌담 ─────────── 차양 기둥
   K01● 돌담 → 북(돌계단·서재)   테라스 [K04● 벤치 → 동 구름]
   돌계단 ↑ K02● (오르며 → 북)     서재 [K03● 책장 → 서]
                                  창가 [K05● 의자 → 동 테라스·구름]
   해: 동쪽 낮게(아침) — 그림자 서쪽으로 길게
```

| 자리 | 높이 | 보는 방향 | 이웃 자리까지 |
|---|---|---|---|
| K01 절벽 돌담(서서) | 1.6 m | 위쪽 서재, 오른쪽 구름 | → K02 약 6 m(생략) |
| K02 돌계단(오름) | 1.6 m(+15 cm/걸음) | 계단 위 서재 | 컷 안에서 2계단, **앞·위로만** |
| K03 서재 책장(서서) | 1.6 m | 책장(서쪽 벽) | 계단 끝에서 문 3 m(생략) |
| K04 테라스 벤치(앉아) | 1.1 m | 구름바다 | 서재 문 밖 4 m(생략) |
| K05 창가 의자(앉아) | 1.1 m | 창 너머 테라스·구름 | 서재 안(생략) |

이음점
- S0 OUT: 안개 걷힌 절벽과 서재 → S1 IN: 같은 화면, 손이 돌담
- S1 OUT: 시선이 돌계단 위로 → S2 IN: 계단 아래, 손이 돌담
- S2 OUT: 두 계단 위에서 멈춤, 서재 문 가까이 → S3 IN: 서재 안, 손이 책
- S3 OUT: 책을 반쯤 꺼냄, 시선이 창 너머 테라스 → S4 IN: 테라스 벤치, 잔
- S4 OUT: 잔을 무릎에, 바람 → S5 IN: 창가 의자, 펼친 책(같은 차양이 창밖에 보임)
- S5 OUT: 책장 한 장 넘기고 손이 멈춤 → 끝

### 2-3. 정글 — 수관 아래 열린 방갈로

```
   폭포(북서) ║  물웅덩이 ~~~ 물길 ~~~
   큰 잎 K01● → 북(쉼터)
   젖은 돌길 K02● (2걸음 → 북)
   ┌──────── 방갈로 지붕(처마 빗줄기) ────────┐
   │ 찻상 [K03● → 북서 폭포]   해먹 [K04● → 서 폭포] │
   │ 문턱 [K05● 앉음 → 북 폭포·물웅덩이]  빗물 사슬 │
   └──────────────────────────────────────┘
   빛: 비구름 아래 고른 회녹색, 실내 등나무 등 1개(호박색)
```

| 자리 | 높이 | 보는 방향 | 이웃 자리까지 |
|---|---|---|---|
| K01 큰 잎 앞(서서) | 1.6 m | 쉼터 정면 | → K02 약 5 m(생략) |
| K02 젖은 돌길(걸음) | 1.6 m | 쉼터 입구 | 컷 안에서 2걸음(1.2 m, 조심스럽게) |
| K03 찻상(서서) | 1.5 m | 폭포 쪽 난간 | 처마 아래 3 m(생략) |
| K04 해먹(기댐) | 0.9 m | 폭포와 등 | 쉼터 안 3 m(생략) |
| K05 문턱(앉아) | 1.0 m | 폭포·물웅덩이 | 쉼터 안(생략) |

이음점
- S0 OUT: 안개가 걷히고 빗소리 → S1 IN: 같은 화면, 손이 큰 잎
- S1 OUT: 잎을 밀어 쉼터가 열림 → S2 IN: 돌길, 손이 나무줄기
- S2 OUT: 처마 아래로 들어서며 빗소리가 지붕 소리로 바뀜 → S3 IN: 찻상, 주전자
- S3 OUT: 물줄기 멈춤, 잔을 듦 → S4 IN: 해먹, 같은 잔
- S4 OUT: 해먹이 멈춤 → S5 IN: 문턱에 앉음, 같은 비
- S5 OUT: 호흡 한 번, 비만 계속 → 끝

### 2-4. 음악방 — 해질녘 도시의 넓은 개인 방

```
   창(서쪽, 높은 창 2개 — 해질녘 빛이 들어옴)
   ┌──────────────────────────────────────────┐
   │ 화분   스피커[오디오 랙 K05●→서]스피커   안락의자 │
   │ L                                    피아노 │
   │ P  라운지 의자  러그                   [K04●→서남] │
   │ 벽                                  기타·드럼 │
   │ K03●(→남 LP벽)      시계 서랍장            │
   │ K02●(LP벽 따라 →서)                         │
   └── 문 K01●(→서, 방 전체) ───────────────────┘
```

| 자리 | 높이 | 보는 방향 | 이웃 자리까지 |
|---|---|---|---|
| K01 문간(서서) | 1.6 m | 방 전체, 창 | → K02 컷 안에서 2걸음 |
| K02 LP벽 앞(걸음) | 1.6 m | 창 쪽 | 컷 안에서 2걸음 |
| K03 LP벽(서서) | 1.6 m | LP 선반 | 같은 벽, 1 m |
| K04 피아노 의자(앉아) | 1.2 m | 건반 너머 방 | 러그 건너 5 m(생략) |
| K05 오디오 랙 앞(서서) | 1.4 m | 랙과 창 | 4 m(생략) |

이음점
- S0 OUT: 안개가 걷히고 방 공기 → S1 IN: 문간, 손이 문틀
- S1 OUT: 두 걸음 들어와 LP벽 옆 → S2 IN: 같은 자리(K02), 손이 선반 모서리
- S2 OUT: 걸음 멈춤, 시선이 LP로 → S3 IN: LP 한 장을 두 손으로
- S3 OUT: 재킷을 반쯤 뺌, 시선이 피아노 → S4 IN: 피아노 의자, 다섯 음
- S4 OUT: 마지막 음의 잔향 → S5 IN: 랙, 노브(같은 잔향이 스피커로 이어짐)
- S5 OUT: 손이 내려가고 바늘 소리만 → 끝

확인 필요: K01에는 피아노가 안쪽 오른쪽 창가에, K04에는 오른쪽 벽 가까이 보입니다. 같은 피아노 1대로 보고 **오른쪽 벽 안쪽**에 둡니다(그림 기준). K04 생성 때 두 번째 피아노가 생기는지 따로 확인합니다.

| 항목 | 정한 것 |
|---|---|
| 도구 | Google Flow **새 프로젝트**, 옴니 모델 (모델 이름·1회 비용·잔액은 Flow 화면에서 확인한 뒤 기록) |
| 프로젝트 이름 | 261103_MineD_나의공간_옴니_v1 |
| 컷 구성 | 공간당 S0–S5, 컷당 8초 |
| 시작 프레임 | S0 = 관측소_안개_START_v2 → 끝 = K01. S1 = K01. S2–S5 = K02–K05 |
| 참조(재료) | 같은 공간의 다른 키프레임을 참조로 함께 넣어 방·물건·빛을 고정(옴니가 허용하는 만큼) |
| 이음 | 위 이음점 표의 OUT → IN을 프롬프트 첫 문장·끝 문장에 그대로 씀. 컷 사이 생략은 같은 화면 방향·같은 환경음으로 잇기 |
| 순서 | 바다 S1(톤 시험) → 바다 나머지 → 하늘산 → 정글 → 음악방, 한 컷씩 |
| 점검 | 컷마다 1초 3장 이상 프레임 확인 + 각 컷 VIDEO WATCH 항목 |
| 금지 | HOLD 5장 입력, 자동 재시도, 다른 제공자, 중복 제출 |
