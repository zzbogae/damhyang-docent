# 이어진 섬: 설계 시연과 실제 연결에 필요한 것

`web/src/islands/Islands.tsx` 는 실제 연결 없이 가상 이웃 세 명(`web/public/islands/demo.json`, 합성 인물 판정 결과로 만든 가짜 데이터)으로 동작을 보여 주는 시연이다. 화면에 "설계 시연 · 가상 이웃"을 표시한다.

## 시연에서 지키는 안전선

- 남의 원문은 보이지 않는다. 이웃 섬에서는 그 사람이 공개하기로 고른 방 이름, 방마다 광물 표본 수, 방명록만 보인다. 글·사진·날짜·판정 문장은 보이지 않는다.
- 방문은 초대로만 한다. 초대 코드를 받은 이웃만 지도와 목록에 나타난다.
- 순위·비교·랭킹이 없다. 이웃은 초대를 받은 순서대로 놓고, 닮음 점수나 정렬을 보여 주지 않는다.
- 내 섬은 기본값으로 아무것도 공개하지 않는다. 공개할 방을 고르면 "이웃에게 보이는 것"을 바로 보여 준다.

## 잇는 기준

- 권장안: 서로 공개한 방 가운데 이름이 같은 방이 있을 때만 다리를 놓는다. 사용자가 고른 이름으로 이어지므로 판정(상태)이 연결 기준이 되지 않는다.
- 원안(비교용): 판정된 주의 광물 분포가 비슷한 섬끼리 잇는다. 광물은 판정 패턴에서 계산되므로, 결국 비슷한 상태의 주를 겪은 사람끼리 잇는 것이 된다. 공개하지 않은 주의 광물까지 이웃에게 드러난다. 시연에서는 이 차이를 설명과 함께 보여 준다.

## 실제로 연결하려면

| 항목 | 필요한 것 |
|---|---|
| 계정 | 별명만 쓰는 계정. 이메일·전화번호는 복구용으로만, 이웃에게는 보이지 않음 |
| 초대 | 일회용 초대 코드, 만료 시간, 초대 취소, 이웃 끊기 |
| 서버에 올라가는 것 | 별명, 공개하기로 고른 방 이름, 방마다 표본 수, 방명록 글 |
| 서버에 올라가지 않는 것 | 원문(메모·카톡), 사진, 날짜, 판정 문장, 지표 값, 공개하지 않은 방과 광물 |
| 안전 | 방명록 신고·차단, 욕설·개인정보 거르기, 위기 표현이 담긴 방명록은 운영자 확인과 109 안내 |
| 동의 | 공개 범위를 바꿀 때마다 미리보기로 다시 확인, 언제든 공개 취소와 서버 데이터 삭제 |
| 운영 | 미성년자 정책, 신고 처리 기준, 데이터 보관 기간 |

"기록은 브라우저 밖으로 나가지 않습니다"라는 약속과 부딪히는 기능이므로, 이어진 섬을 켜는 순간 무엇이 밖으로 나가는지를 사용자가 직접 보고 고르게 해야 한다.
