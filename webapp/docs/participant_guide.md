# Mine D 실제 기록 평가 안내(참가자용)

Mine D 가 실제 기록에서도 「평소와 달랐던 주」를 제대로 찾는지 확인하려고 합니다. 30분에서 1시간 정도 걸립니다. 기록은 여러분의 컴퓨터 밖으로 나가지 않고, 멘토에게는 **숫자만 담긴 보고서 파일 하나**만 보내 주시면 됩니다.

## 준비해 주세요

- 크롬 또는 엣지 브라우저가 있는 컴퓨터
- 멘토에게 받은 참가 코드(P1~P4)
- 가져올 기록(있는 것만): 구글 테이크아웃(유튜브·Keep·캘린더·포토), 아이폰 건강 또는 삼성 헬스 내보내기, 카카오톡 대화 내보내기, 사진 폴더

## 순서

1. 앱 주소 끝에 `?eval` 을 붙여 열어 주세요.
2. **기록을 가져오기 전에** 「사건 먼저 적기」를 눌러, 날짜가 확실한 일을 5~15개 적어 주세요.
   - 힘들었던 일(아팠던 주, 시험·마감 등)
   - 좋았거나 특별했던 일(여행, 행사 등)
   - 그 뒤로 생활이 달라진 일(이사, 입학, 이직 등 — 시작한 날만)
3. 「봉인하기」를 눌러 주세요. 봉인한 뒤에는 목록을 고치지 않는 것이 이 평가의 핵심입니다.
4. 기록을 가져와 주세요. 15년치는 몇 분 걸릴 수 있습니다.
5. 지층 화면을 보기 전에 「평가」 → 「가린 주 고르기」에서 나오는 주마다 기억에 남는지 답해 주세요.
6. 참가 코드를 적고 「계산하기」를 누른 뒤, 화면의 숫자를 한 번 확인하고 「보고서 내려받기」를 눌러 주세요.
7. 내려받은 `mined_eval_<코드>.json` 파일 하나만 멘토에게 보내 주세요.

## 보내지 않는 것

메모·메시지·사진 원문, 날짜, 사건 내용, 이름은 보고서에 들어가지 않습니다. 날짜처럼 보이는 값이 하나라도 섞이면 앱이 보고서를 만들지 않습니다.

## 막히면

가져오기에서 멈추거나 오류가 나면 화면을 캡처해 멘토에게 보내 주세요. 기록 파일 자체는 보내지 않으셔도 됩니다.
