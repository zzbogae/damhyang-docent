## 깃허브에 올리기

```bash
bash push.sh
```

`gh` CLI가 있으면 저장소 생성까지 자동입니다. 없으면 스크립트가 안내합니다.
커밋 전 개인정보 검사가 자동으로 돌아갑니다.

---

## 저장소 구조

```
docs/     설계 문서. 여기가 이 저장소의 본체입니다
app/      단일 HTML 프로토타입 (의존성 없음 — 브라우저로 바로 열림)
pipeline/ gyeol_kit — 데이터 파서·판정 로직 (각자 로컬에서 복사)
```

### 앱 실행

```bash
open app/mined_app.html
```

내보낸 JSON을 화면에 끌어다 놓으면 지도가 그려집니다. 설치할 것 없습니다.

### 파이프라인 실행

`pipeline/`은 비어 있습니다. 각자 로컬 `gyeol_kit/`을 복사해 넣으세요.

```bash
python3 run_gyeol.py                    # 리포트
python3 export_app_data.py --who "이름"   # 앱용 JSON
```

표준 라이브러리만 씁니다. 네트워크 접속 코드 없습니다.

## ⚠ 절대 원칙 — 코드를 짜기 전에 읽으세요

1. **회복을 확신할 수 없으면 회복이라고 말하지 않는다**
2. **판정하지 않고 관찰한다** (광물 이름만 — 진단어 금지)
3. 벌점·스트릭·화폐·상점·랜덤뽑기 없음
4. 사용자가 꾸미지 않는다 (배치·이름·연결만)
5. **AI가 안 한 일을 했다고 말하지 않는다** (코어는 절차적 생성)
6. 설명 없이 3초 안에 이해되어야 한다

### 표현 금지 목록

- 임상적·진단적 언어 ("우울", "번아웃", "위험군")
- 바넘 효과식 문장 (달콤한 두루뭉술함)
- 완전한 해소·봉합으로 끝내기 — 흔적을 남긴다
- 패턴에 해석적 이름 붙이기 ("회복 사이클") — 모양만 말한다
- 좋음/나쁨 판정 — **적음/많음**으로 쓴다
